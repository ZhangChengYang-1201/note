## 二、毕设推进详细过程说明

**工作内容**：完成SciBERT语义向量生成与论文语义相似网络的构建

### 1. 背景与目标
本研究的核心创新点之一是引入SciBERT预训练语言模型替代传统共词网络，将学科交叉测度的分析单元从“关键词粒度”提升至“论文粒度”。为此，需要将全部13,898篇有效论文的标题与摘要转化为可用于相似度计算的语义向量，并基于向量构建论文语义相似网络。

### 2. 语义向量生成过程
- **模型选型**：选用SciBERT（allenai/scibert_scivocab_uncased），该模型基于百万级科学论文语料预训练，科学词表与通用BERT重合度仅42%，对学术文本语义提取具有针对性优势
- **编码方式**：将每篇论文清洗后的标题与摘要拼接为连续文本，截断至512 token，取SciBERT最后一层[CLS] token的输出向量作为768维语义表征
- **向量归一化**：对所有生成的论文向量进行L2归一化处理，使得向量内积直接反映余弦相似度，如公式(3.1)所示
- **批量编码策略**：使用Sentence-Transformers库分批加载论文文本，batch_size=32，在GPU（RTX 3060）上完成编码，总耗时约3小时

### 3. 语义相似网络构建
- **互惠k-近邻策略**：设定k=50，仅在两篇论文互为语义最近邻时才建立连边，以余弦相似度作为边权重，有效滤除单向弱关联噪声
- **模块度最优阈值筛选**：在候选阈值区间[0.65, 0.90]内以步长0.05进行网格搜索，对每个阈值构建网络并运行Louvain算法，选取使模块度最大化的阈值作为该年度最优阈值
- **构建结果**：各年度网络模块度集中在0.50—0.59之间，2018年、2019年、2020年模块度表现尤为突出，表明语义相似网络社区结构清晰，为后续的主题聚类提供了良好基础

### 4. 遇到的问题与解决
在构建2015年语义相似网络时，阈值为0.80时模块度最高（0.5772），但网络边数仅16,699条，存在部分论文节点孤立的情况。经分析发现，这些孤立论文多为跨学科特征极强或语言非英语的论文，其语义向量与同年度主流论文差异较大。考虑到孤立论文同样承载重要的学科交叉信息，我调整策略：在最终主题识别的后处理阶段设定最小主题规模为5篇，将无法归入任何社区的孤立论文单独标记，供后续定性分析参考，而非直接丢弃。

## 三、专业学习详细过程说明

**学习内容**：精读SciBERT原论文并深入理解Louvain社区发现算法

### 1. SciBERT论文学习
本周用两天时间系统精读了SciBERT原论文《SciBERT: A Pretrained Language Model for Scientific Text》（Beltagy et al., 2019），重点理解三个方面：
- **预训练语料构建**：SciBERT基于114万篇Semantic Scholar科学论文训练，覆盖计算机科学、生物医学等多个领域，语料的广度和专业性是其与通用BERT的根本差异
- **定制词表策略**：训练专门的WordPiece词表（scivocab），保留更多科学术语完整形式，避免通用BERT词表中高频科学词汇被拆分为无意义的子词。论文给出的42%词表重叠率数据，直观说明了定制词表对学术文本编码的必要性
- **任务适配性**：在NER、PICO抽取、文本分类、关系抽取等下游科学NLP任务上全面超越通用BERT，验证了领域预训练的有效性

### 2. Louvain算法学习
结合论文第三章的研究设计需要，系统性回顾了Louvain社区发现算法的原理：
- **模块度定义**：理解模块度Q衡量的是网络中社区内部边数与随机网络中期望边数的差异，其值域为[-0.5, 1]，Q>0.3通常表明网络具有显著的社区结构
- **两阶段优化**：第一阶段以贪心方式将每个节点移动到使模块度增益最大的相邻社区；第二阶段将第一阶段发现的社区压缩为超节点，迭代执行上述过程，直至模块度不再提升
- **算法优势**：计算效率高、无需预设社区总数、适用于大规模网络

### 3. 遇到的问题与解决
在理解SciBERT的[CLS]向量为何能作为整篇论文的语义表征时产生困惑——毕竟[CLS]在BERT中设计为“聚合序列信息”的占位符，但论文输出仅取[CLS]向量是否会丢失细节信息？通过查阅Sentence-Transformers文档和相关论文，了解到均值池化策略（取所有token输出向量的均值）是更稳健的句子级表征方案。为验证，我编写了一个小对比实验：对200篇论文分别采用[CLS]池化和均值池化，发现均值池化后论文向量的聚类轮廓系数更高（从0.32提升至0.41），最终在正式实验中改用均值池化策略。这一调整也更新到了论文第三章的表征方法描述中。
